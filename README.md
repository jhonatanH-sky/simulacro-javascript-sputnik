# Simulacro Módulo 3 - JavaScript

Este proyecto contendrá el simulacro correspondiente al **Módulo 3 de JavaScript**.

El objetivo es practicar y evaluar los conocimientos adquiridos durante el módulo, aplicando conceptos clave de JavaScript a través de ejercicios y desafíos similares a los de una evaluación real.

## Contenido
- Ejercicios prácticos de JavaScript
- SPA
- Resolución de problemas
- Simulación de evaluación del módulo
